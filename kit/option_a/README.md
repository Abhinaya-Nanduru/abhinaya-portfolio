# Option A: everything happens in your browser

Nothing to download. Nothing to install. No terminal.

## The two files you will copy from

**`1_COPY_THIS_ai_draft_page.txt`**
The page an AI wrote. Click it, select all the text, copy it. This is what
you audit.

**`2_COPY_THIS_starter_page.txt`**
A clean page to build your own from. Same thing: click, select all, copy.

The `.txt` versions exist so you can read and copy the code directly. The
`.html` versions of the same two files are here as well, if you would rather
open them and look at the page itself first.

## The editor you will paste into

Go to **w3schools.com/html/tryit.asp?filename=tryhtml_default**

Select everything already in the left-hand box, delete it, paste your code
in, and press **Run**. Your page appears on the right.

It is free, it needs no account, and nothing is saved anywhere. If you break
something badly, reload the page and paste again.

You can use any other online editor you prefer. CodePen, JSFiddle and
PlayCode all work the same way. The instructions say W3Schools because it is
the site from the session and it needs no sign-up.

## What you hand in

A written audit, and the screenshots the assignment asks for. No web address,
no deployment. Option B is where that starts.

## One rule, even here

There is an API key in the draft page. It is fake and it was put there on
purpose for you to find.

**Do not screenshot it anyway.** Write down the line number instead.

Get into the habit now, while it costs you nothing. The day you screenshot a
real one is the day it stops being free.
